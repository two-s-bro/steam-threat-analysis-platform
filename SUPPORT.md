# Support

Use GitHub Issues for reproducible bugs, documentation corrections, safe feature proposals, and detection-rule false positives. Include the revision, operating system, Java/Node versions, and a synthetic reproduction.

This project cannot provide malware removal guarantees, emergency incident response, account recovery, legal advice, or analysis of uploaded samples. For an active compromise, disconnect the affected system as appropriate and contact a qualified incident-response provider or your organization's security team.

For vulnerabilities in this repository, follow [SECURITY.md](SECURITY.md).
