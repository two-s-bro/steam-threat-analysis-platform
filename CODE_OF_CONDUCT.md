# Code of conduct

Contributors must communicate professionally, respect privacy, accept evidence-based review, and avoid harassment or discrimination. Security research must remain defensive, authorized, and safe for public collaboration.

Maintainers may edit or remove content that exposes personal data, credentials, unsafe artifacts, live malicious infrastructure, or operational abuse instructions. Repeated or serious violations may result in restricted participation.

Report conduct concerns through a private repository security channel where possible; do not expose another person's private information in a public Issue.
