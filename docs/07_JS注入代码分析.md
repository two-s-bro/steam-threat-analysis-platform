## 直接观察

静态差异显示，帮助与支持相关的路由解析区域被修改。被影响的路由语义包括应用帮助、帮助首页和支持消息；异常目的地是已去武器化的历史 C2 端点。其他客户端功能仍可能表面正常，因此仅靠用户体验难以及时发现。

本项目不公开具体语法、变量、控制流拼接或回退实现，避免把事件记录变成可重新武器化的补丁蓝图。

## 防御检测

| 数据源 | 推荐信号 | 注意事项 |
|--------|----------|----------|
| 文件完整性 | 与同版本可信 Steam UI 文件比较哈希 | 客户端更新会产生合法变化 |
| 文件写入遥测 | 非 Steam 更新进程修改 `steamui/` | 结合签名、父进程和更新时间 |
| 静态内容 | 帮助路由词与 `nexustechsolution[.]top` 同时出现 | 单独路由词不是恶意证据 |
| 配置 | UI 修改后出现禁用更新配置 | 组织自定义配置可能产生误报 |
| 持久化 | 同期出现异常用户级 Run 键 | 必须核验完整路径和哈希 |

## 响应建议

1. 先保留哈希、版本和修改时间等证据；
2. 由可信安装介质或官方客户端恢复文件完整性；
3. 调查执行写入的进程和同时间窗口内的持久化变化；
4. 不执行私有证据中的脚本，也不尝试把差异应用到客户端；
5. 将结论标注为直接观察、推断或未知。

当前 Steam 版本和可信哈希会变化，本仓库不维护“全版本官方哈希”列表。检测系统应从组织认可的基线生成比较值。
