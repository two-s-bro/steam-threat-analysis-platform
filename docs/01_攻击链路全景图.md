# 攻击链路全景图

本页把私有事件证据映射为防御阶段，不提供样本执行、载荷恢复、客户端补丁或钓鱼界面复刻步骤。

## 阶段概览

| 阶段 | 证据支持的行为 | 推荐数据源 |
|------|----------------|------------|
| 0. 欺骗传播 | 用户从不可信来源取得伪装资源 | 下载历史、浏览器与邮件/聊天安全记录 |
| 1. 首阶段落地 | 多个异常组件出现在用户目录，并建立用户级 Run 键 | EDR 文件遥测、注册表审计、SHA-256 |
| 2. 客户端篡改 | Steam 进程和 UI 文件发生异常变化，更新配置被修改 | 进程树、文件完整性、配置审计 |
| 3. 社会工程 | 客户端内出现仿冒支持通知，帮助路由指向异常目的地 | UI 资源清单、代理/DNS 历史、账号安全日志 |
| 4. 历史心跳 | 脱敏日志中持续出现周期性记录 | 已保全日志、EDR 与代理历史 |

## 关键组件关系

| 组件/信号 | 防御性角色 | 证据等级 |
|-----------|------------|----------|
| `SteelDungeon.exe` | 与首阶段落地和后续组件聚类相关 | 静态元数据 + 日志关联 |
| `NexusTechNotify.exe` | 与 Steam 进程控制、文件修改和周期检查相关 | 日志直接观察 |
| `locale_patch.dll` | 与本地通知资源同批出现 | 文件关联；具体注入机制未知 |
| Steam UI chunk 变化 | 帮助/支持路由区域出现异常目的地 | 静态差异观察 |
| `steam.cfg` 变化 | 更新相关配置被禁用 | 日志与配置内容观察 |
| `nexustechsolution[.]top` | 历史异常基础设施 | 去武器化 IOC；当前状态未检查 |

## 跨阶段检测机会

1. 用户目录中新组件与 Run 键在短时间内同时出现；
2. 非可信进程终止 Steam 后写入 `steamui/`；
3. UI 文件修改与禁用更新配置同时出现；
4. 帮助/支持路由词与去武器化 IOC 同时出现；
5. 上述主机证据与账号安全异常或代理历史相关。

单个文件名、路由词或配置项都可能有正常解释。检测应组合多源证据，并记录置信度和误报条件。

## 未知项

- 初始下载来源没有被独立确认；
- DLL 的具体加载/注入机制没有在公开研究中验证；
- 远端是否接收、保存或进一步使用数据没有服务器端证据；
- 私有日志停止不证明终端已清理或基础设施已下线。
