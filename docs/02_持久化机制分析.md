## 状态文件观察

私有证据中的 `.state.json` 包含下载状态和一个用户目录下的组件路径。公开报告删除了用户名及完整工作站路径，只保留其“用户级状态记录”这一防御性结论。该文件可能被用于避免重复下载；这一用途属于静态推断。

## 持久化启动链

```
系统启动
  → HKCU\Run\SteamHelper → lizercllaxe.exe
  → HKCU\Run\SteamService → snapshot.exe
  → HKCU\Run\WindowsUpdateService → gameSatorHost.exe
     └─ 任一启动成功 → 检查/恢复其他两个 → 守护 Steam 补丁
```

多个 Run 键增加了清理遗漏的可能性。现有证据支持“组件会互相检查”的推断，但本项目没有在公开环境中动态验证完整恢复能力。
