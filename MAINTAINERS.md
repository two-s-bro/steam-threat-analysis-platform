# Maintainers

| Maintainer | Role | Responsibilities |
|------------|------|------------------|
| [@two-s-bro](https://github.com/two-s-bro) | Owner and primary maintainer | Roadmap, review, releases, security triage, evidence-safety policy |

The primary maintainer is responsible for keeping raw incident evidence outside GitHub, reviewing every data-bearing change, responding to actionable Issues, and publishing only changes that pass the public-safety gate.

Maintainer status is based on repository ownership and active responsibility; this file does not claim external adoption or organizational endorsement.
